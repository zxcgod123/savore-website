# SAVORÉ

Every Scene, Savored. Учебный визуальный проект киноужинов.

## Публикация

Загрузите `index.html`, `style.css`, `script.js` и папку `assets` в корень публичного репозитория GitHub. Settings → Pages → Deploy from a branch → main / (root).

## Важно

Цены, свободные места и бронирование демонстрационные. Таймкоды блюд примерные, не сверены с монтажной версией фильмов. Постеры подгружаются с TMDB через внешние URL, поэтому требуют интернет и могут быть недоступны. Логотип сохранён из изображения заказчика без изменений.
